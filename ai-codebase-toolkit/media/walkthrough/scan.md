# Scan

The scanner inspects your project (no LLM calls) and gives you:

- **Stack:** language, frameworks, package manager, test framework.
- **Structure:** source root, top-level folders, large folders that may need splitting.
- **Conventions:** dominant file naming and consistency %.
- **AI presence:** which assistants already have rules files.

The score (0–100) tells you how ready the codebase is for AI assistance.
