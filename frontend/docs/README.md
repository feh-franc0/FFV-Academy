# Documentation site

This folder contains a [VitePress](https://vitepress.dev) site for the project's docs.

## Run locally
```bash
cd docs
npm install
npm run docs:dev
```

Then open the printed URL (default http://localhost:5173).

## Build static site
```bash
npm run docs:build
```

The static site is emitted to `.vitepress/dist`.

## Authoring
Pages are plain Markdown. Mermaid diagrams use fenced \`\`\`mermaid blocks.
The structure is generated by **AI Toolkit: Generate Documentation Site** —
re-run it to regenerate the skeleton when the project evolves significantly.
