✅ PRONTO PARA USAR
Esta pasta contém 144 arquivos HTML/CSS/JS estáticos prontos para publicar.

Não precisa de Node.js, não precisa de servidor especial.

════════════════════════════════════════════════════════════════
COMO COLOCAR NA HOSTINGER
════════════════════════════════════════════════════════════════

1. Acesse o painel da Hostinger
2. Vá em "Gerenciador de Arquivos" ou "File Manager"
3. Navegue até a pasta public_html (ou raiz do seu domínio)
4. Faça upload de TODOS os arquivos desta pasta "deploy/"
   - Clique com botão direito e escolha "Upload"
   - Ou arraste os arquivos direto

5. Verifique:
   - Certifique-se que index.html está na raiz (public_html)
   - As pastas _next, aprenda, fundamentos-da-ia, ia-alem-do-llm devem estar lá também

6. Acesse seu domínio: https://seudominio.com
   - Tudo deve carregar normalmente
   - O progresso do usuário é salvo no localStorage do navegador

════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════

❌ Páginas retornam erro 404?
   → Verifique se todos os arquivos foram upados com as pastas
   → Tente acessar a URL exata (ex: /aprenda/o-que-e-ia/)

❌ CSS/JS não carregam?
   → Limpe o cache do navegador (Ctrl+Shift+Del)
   → Verifique se a pasta _next/ está presente

❌ Cliques não funcionam?
   → Verifique o console do navegador (F12)
   → Se vir erros de CORS, é normal em arquivo local - funciona ao vivo

════════════════════════════════════════════════════════════════
ATUALIZAR O SITE
════════════════════════════════════════════════════════════════

Se você fizer mudanças no código e quiser atualizar o site:

1. Na sua máquina: npm run build
2. Copie a pasta deploy/ novamente
3. Delete tudo na Hostinger e coloque os novos arquivos
   (ou use a opção "Replace" no file manager)

SUPORTE / DÚVIDAS
════════════════════════════════════════════════════════════════

Este é um site 100% estático. Não precisa de PHP, banco de dados
ou nada especial. Se não funcionar, é porque os arquivos não foram
upados certo ou falta alguma coisa.
