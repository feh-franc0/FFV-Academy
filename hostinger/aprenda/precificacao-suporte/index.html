Precificação, Free Tier e Planos de Suporte

⏱ 10 min de leitura·+50 XP

Nenhum domínio gera mais surpresa em clientes novos da AWS do que o pagamento. O modelo pay-as-you-go é flexível, mas pode gerar faturas inesperadas. O CLF-C02 cobra os fundamentos de pricing, as ferramentas de análise de custos, e os 4 planos de suporte AWS — especialmente os limites de cada um.

Onde isso entra no exame

📘 Domain 4 — Billing, Pricing, and Support· 12%

Menor domínio em peso (12%) mas alta densidade de decoreba: planos de suporte, ferramentas de billing, free tier. As questões são geralmente objetivas ("qual ferramenta para X?", "qual plano inclui Y?").

Os 3 pilares do pricing AWS

PilarDescrição
ComputeHora/segundo de EC2, Lambda invocações + duração, Fargate vCPU+GB
StorageGB-mês de S3/EBS/EFS, requisições S3, transferência entre classes
Data TransferOUT para internet (é o que mais surpreende). IN quase sempre grátis. Entre AZs na mesma Região: pago.
⚠️
Pegadinha de custo: transferir dados OUT (para internet) custa. Transferir entre AZs dentro da Região também custa (≈$0.01/GB). Transferir entre Regiões é mais caro. Dados IN (internet → AWS) quase sempre são grátis.

AWS Free Tier — 3 tipos

TipoDuraçãoExemplo
12-month free12 meses a partir da abertura da conta750h/mês de t2.micro ou t3.micro EC2, 5 GB S3

Muitos serviços têm Free Tier. Alguns notáveis: Lambda, DynamoDB, CloudWatch (10 custom metrics + 1M API requests), SNS (1M publishes), SQS (1M requests). Verifique sempre aws.amazon.com/free.

AWS Organizations e Consolidated Billing

AWS Organizations permite gerenciar múltiplas contas AWS como uma única unidade. Benefícios:

  • • Consolidated Billing — uma fatura única para todas as contas
  • • Volume discounts — soma de uso entre contas aumenta descontos por tier
  • • Reserved Instance / Savings Plans sharing — RIs compradas em uma conta beneficiam outras
  • • Service Control Policies (SCPs) — limites máximos de permissões em nível de OU/conta
  • • Integração com Control Tower (landing zone) e SSO

AWS Abuse e outros contatos grátis

Algumas operações não exigem plano pago:

  • • AWS Abuse — reportar abuso de IP AWS (phishing, malware)
  • • AWS Trust & Safety — questões legais
  • • Questões de faturamento — todos os planos podem abrir ticket
  • • Suporte Basic cobre: disponibilidade de serviços AWS, questões de conta e billing

Cenários de decisão

📋 Startup com MVP rodando $1k/mês, quer alertas quando passar de $1.5k

✓ AWS Budgets + SNS email alert

Budgets é grátis para os 2 primeiros e notifica via SNS. Cost Explorer é análise retroativa; Budgets é proativo.

📋 Empresa com 30 contas AWS, cada time compra RI separadamente

✓ AWS Organizations + Consolidated Billing + RI/Savings Plans sharing

Consolida cobrança, aumenta volume discount, permite RIs compradas em qualquer conta beneficiarem outras. Economia imediata.

📋 Banco com SLA de 15 min para P1, suporte 24/7 e acesso a TAM dedicado

✓ Enterprise Support Plan

Único plano com TAM dedicado e SLA <15min para P1. $15k/mês mínimo. Inclui WAR Reviews ilimitadas.

Alt: Enterprise On-Ramp — TAM em pool (não dedicado), SLA 30 min — ~1/3 do custo

📋 Devs internos testando AWS, querem suporte técnico via email em horário comercial

✓ Developer Support ($29/mês ou 3% do uso)

Atende times de dev/teste. Para produção crítica, upgrade para Business.

💡
Dica forte para o exame: decore o menor plano que inclui cada feature. TAM dedicado = só Enterprise. 24/7 = Business+. Todos os Trusted Advisor checks = Business+. Third-party software (OS/DB) support = Business+. Well-Architected Reviews = Enterprise On-Ramp+.

Perguntas típicas (Q&A)

❓ Qual ferramenta estima o custo de uma arquitetura antes de provisioná-la?

AWS Pricing Calculator. Selecione serviços, configure, compartilhe link. Ideal para apresentações e aprovações orçamentárias.

❓ Em qual plano de suporte aparece AWS IQ e API de suporte?

Developer em diante. IQ conecta clientes a experts independentes da AWS. API de suporte (acesso programático a tickets) está em Business+.

❓ Quem é dono da conta pagadora em AWS Organizations?

A Management Account (antes chamada "Master Account"). É a conta que recebe a fatura consolidada e tem privilégios superiores (inclui criar SCPs). Não deve rodar workloads de produção.

❓ Qual é o plano de suporte da conta Basic e por quanto tempo?

Basic é grátis e eterno. Inclui acesso a documentação, whitepapers, fóruns da comunidade, 6 Trusted Advisor checks básicos e Personal Health Dashboard. Não inclui suporte técnico humano.
✅
Take-aways:Compute + Storage + Data Transfer OUT são os 3 custos principais. Free Tier tem 12 meses, always-free e trials. Savings Plans > RIs para maioria (mais flexível). Organizations = multi-account + consolidated billing + volume discounts. 4 planos de suporte: Basic (grátis) / Developer ($29) / Business ($100+) / Enterprise ($15k+), e o Enterprise On-Ramp entre os dois últimos. TAM dedicado só Enterprise. Budgets (proativo) + Cost Explorer (retrospectivo) + Pricing Calculator (pre-emptivo).
